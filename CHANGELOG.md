# Changelog

All notable changes to **imamzain.org** are documented here.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Version numbers follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html), interpreted for a website as:

- **MAJOR** — visible redesign, URL structure change, auth/data model swap, or anything that breaks deep links / external integrations.
- **MINOR** — new page, new section, new user-facing feature.
- **PATCH** — bug fix, content correction, performance improvement, polish, dependency bump.

Entries are generated by `bun run release` from Conventional Commit messages on `main`. Do not edit released sections by hand — fix the next release instead.
